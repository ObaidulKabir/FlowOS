🤖 AI Agent & Browser Guideline: How to Get MCP Tools

21 Production Tools • 10/10 Score

FlowOS is an authoritative multi-tenant, state-machine-governed workflow control plane with an Model Context Protocol (MCP) interface. Any autonomous AI agent, web crawler, or browser-based AI model can discover, validate, execute, and monitor workflows under strict zero-trust governance.

Step 1: Public Tool Discovery (Zero Credentials Required)

Navigate to or fetch the discovery endpoint. FlowOS separates public discovery from authenticated execution:

  • Interactive Browser Portal: Open https://flowos.prospectbdltd.com/mcp in any browser or web agent to view the interactive tool documentation and security contract.
  • Machine-Readable JSON: Issue an HTTP GET /mcp with header Accept: application/json to receive all 21 tools, formal parameter JSON schemas, risk ratings, and human confirmation policies:
curl -s https://flowos.prospectbdltd.com/mcp -H "Accept: application/json"

Step 2: Connect & Execute Tools (Streamable JSON-RPC 2.0)

All agent mutations, task completions, and status inspections run via POST /mcp over Streamable HTTP:

  • Transport URL: https://flowos.prospectbdltd.com/mcp
  • Required Headers: x-tenant-id: <tenant-guid>, X-MCP-API-Key: <key>, MCP-Protocol-Version: 2025-03-26
  • Sandbox Mode: When API key is unconfigured or set to "disabled", full tool execution is open for instant evaluation!
curl -s -X POST https://flowos.prospectbdltd.com/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "x-tenant-id: 22222222-2222-2222-2222-222222222222" \
  -H "X-MCP-API-Key: flowos_prod_secret_key_32_chars_min" \
  -H "MCP-Protocol-Version: 2025-03-26" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Step 3: Governance Policies & Human Confirmation Gates

  • Machine-Enforced Human Gate: High-risk operations (e.g. publish_workflowclass) strictly require confirmHumanApproval: true. Invocations without explicit human confirmation fail with MCP-APPROVAL-REQUIRED.
  • Object-Level IDOR Protection: Resources of foreign tenants yield uniform MCP-NOTFOUND-001 errors with zero metadata leakage (anti-enumeration).
  • Cross-Tenant Public Blueprints: Blueprints with Scope == Public can be launched across any tenant via start_workflow, while runtime state is completely isolated to the caller.
