🤖 Native Model Context Protocol (MCP) Server

FlowOS exposes a dedicated 21-tool MCP endpoint at /mcp using JSON-RPC 2.0. Autonomous AI agents (such as Claude Desktop, Cursor, and custom LLMs) can securely discover, start, monitor, and advance tenant workflows under zero-trust governance boundaries.

  • Workflow Discovery: describe_workflowclass_schema, list_public_workflowclasses, list_draft_workflowclasses
  • Execution Control: start_workflow, publish_event, complete_task, list_workflow_instances, get_workflow_history
  • Intelligent Diagnostics: suggest_agent_action, explain_validation_violation, lint_draft_workflowclass
  • Governance Lifecycle: create_draft_workflowclass, validate_draft_workflowclass, publish_workflowclass
