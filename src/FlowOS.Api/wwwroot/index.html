⚡ Connect to FlowOS MCP Control Plane (/mcp) ↗

Step 1: Public Tool Discovery (Zero Credentials Required)

Navigate to or fetch the discovery endpoint. FlowOS separates public discovery from authenticated execution:

  • Interactive Browser Portal: Open https://flowos.prospectbdltd.com/mcp in any browser or web agent to view the interactive tool documentation and security contract.
  • Machine-Readable JSON: Issue an HTTP GET /mcp with header Accept: application/json to receive all 61 tools, formal parameter JSON schemas, risk ratings, and human confirmation policies:
curl -s https://flowos.prospectbdltd.com/mcp -H "Accept: application/json"

Step 2: Connect & Execute Tools (Streamable JSON-RPC 2.0)

All agent mutations, task completions, and status inspections run via POST /mcp over Streamable HTTP:

  • Transport URL: https://flowosbd.com/mcp
  • Required Headers: x-tenant-id: <YOUR_TENANT_ID>, X-MCP-API-Key: <YOUR_MCP_API_KEY>, MCP-Protocol-Version: 2025-03-26
  • Sandbox: Launch Live Sandbox on the dashboard. Leaving the API key blank does not open production execution.
curl -s -X POST https://flowosbd.com/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "x-tenant-id: <YOUR_TENANT_ID>" \
  -H "X-MCP-API-Key: <YOUR_MCP_API_KEY>" \
  -H "MCP-Protocol-Version: 2025-03-26" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
